# Quick Print Export

QGIS 3.x 向けのプラグインです。レイアウトマネージャーを使わずに、印刷範囲の座標、縮尺、図面角度を直接指定して、現在のキャンバスを PDF / PNG として出力できます。

## 機能概要

- 出力形式の切り替え: PDF / PNG
- 用紙サイズの指定
  - A0 / A1 / A2 / A3 / A4
  - カスタムサイズ
- 縦横方向の切り替え
- 自動縮尺または手動縮尺指定
- 図面回転角の指定
- 範囲指定
  - 現在のキャンバス表示範囲を利用
  - 全レイヤの表示範囲を利用
  - キャンバス上でドラッグして指定
- プレビュー機能
- 座標ラベルとスケールバーの自動追加

## インストール

1. このプラグインを QGIS のプラグインディレクトリに配置します。
   - 例: `C:\Users\<ユーザー名>\AppData\Roaming\QGIS\QGIS3\profiles\default\python\plugins\quick_print_export`
2. QGIS を再起動します。
3. メニューまたはツールバーから `座標指定 印刷/エクスポート` を起動します。

## 使い方

### 1. 出力設定

- `出力形式` で PDF または PNG を選択します。
- PNG の場合は `解像度(DPI, PNG時)` を指定します。

### 2. 用紙設定

- `用紙サイズ` でプリセットまたは `カスタム` を選択します。
- `縦` / `横` の切り替えができます。
- カスタム時は `幅` / `高さ` を直接入力できます。

### 3. 縮尺・回転

- `自動縮尺(範囲を用紙いっぱいに合わせる)` を有効にすると、範囲に対して用紙いっぱいに収まるように縮尺を自動計算します。
- 無効にすると `縮尺` を手動で入力できます。
- `図面角度` に回転角を設定できます。

### 4. 印刷範囲(座標)

次の方法で出力範囲を指定できます。

- `現在のキャンバス表示`: 現在見えている範囲をそのまま利用
- `全レイヤの表示範囲`: 現在のプロジェクト内の全レイヤ範囲を結合して利用
- `キャンバスでドラッグ指定`: 地図上で矩形をドラッグして範囲を指定

座標値は `用紙左下座標` と `用紙右上座標` に反映されます。

### 5. 範囲・縮尺を計算

- `範囲・縮尺を計算(用紙の縦横比に合わせる)` を押すと、入力した座標範囲と用紙サイズから最適な縮尺とマップ範囲を計算します。
- 自動縮尺時は対応する縮尺値が自動的に反映されます。

### 6. プレビュー / 出力

- `プレビュー` を押すと、レイアウトデザイナーでプレビューを開きます。
- `出力実行` を押すと PDF / PNG で保存します。

## 追加される表示要素

プレビュー・出力時には以下の要素が自動的にレイアウトに追加されます。

- 左下の座標ラベル
- 右上の座標ラベル
- 右下のスケールバー
- `1:縮尺` のテキスト表示

## 注意事項

- このプラグインは元のレイアウトを編集せず、出力用の一時レイアウトを作成して利用します。
- `PNG` 出力時は `解像度(DPI)` が反映されます。
- `カスタム` を選択した場合は、用紙幅・高さを直接入力できます。
